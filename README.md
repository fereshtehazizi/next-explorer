# World Explorer

World Explorer is a modern country exploration web application built with Next.js. It allows users to discover countries around the world, explore detailed information about each country, and search through real-time country data using the REST Countries API.

# Features

* Built with Next.js App Router
* File-based routing system
* Shared layouts
* Dynamic country detail pages
* Server Components and Client Components
* Real-time API data fetching
* Static rendering and caching
* Dynamic rendering
* Country search functionality
* Responsive design
* Filter countries by region
* Clean and modern UI
* Optimized performance

# Getting Started

## Clone the Repository

```bash
git clone github.com/fereshtehazizi/next-explorer
```

## Navigate to the Project Folder

```bash
cd world-explorer
```

## Install Dependencies

```bash
npm install
```

## Run the Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the project.
